# HER-200-Track-3-ElevateHER
Group 2 Track 3 ElevateHER

"Uplift" is an app/dashboard that helps women build real leadership experience. Women who have already led a team, a club or a project are more likely to step into leadership roles later. "Uplift" makes that path clear: it shows each user where she stands today and which experiences will move her forward.

Our approach

ElevateHER turns leadership growth into a clear path that you can measure:

Leadership readiness score: a progress bar from 0% to 100% shows how ready a user is for leadership opportunities.
Six core experiences: users log the experiences that build leadership, and each one moves the score forward:

&check;Being a mentor

&check;President of a club

&check;Leading a project

&check;Doing research

&check;Panel experience

&check;Internship experience

Visible progress: each logged experience shows a woman what she has already done and what to do next.
